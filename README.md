# Treasure Hunt Game

A C++ console-based game where a player competes against a computer opponent to locate hidden treasures on a 5x5 game board.

## Features

- Object-oriented design using C++
- Player vs computer gameplay
- Randomized treasure placement
- Input validation
- Hit/miss tracking
- File output for game results

## Technologies

- C++
- Standard Template Library (STL)
- Object-Oriented Programming
- File I/O

## How to Run

Compile:

g++ main.cpp GameBoard.cpp -o TreasureHunt

Run:

./TreasureHunt
